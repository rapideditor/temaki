# Decisions

## Build pipeline

- Icons live in `icons/` as individual `.svg` files. `bun run all` lints, type-checks, and rebuilds everything.
- `scripts/check.ts` is the main linter — it normalizes SVG structure, converts shapes to paths, and writes files in-place.
- `data/icons.json` maps icon names to groups. `scripts/metadata.ts` validates and regenerates it.
- The preview page (`docs/index.html`) is generated by `svg-sprite` from a Mustache template.
- `bun start` serves `docs/` and `dist/` locally at `http://127.0.0.1:8080/`.

## No ESM-only or package-checks playbooks

The agent-practices [ESM only](https://github.com/rapideditor/agent-practices/blob/main/playbooks/esm-only.md) and [Package checks](https://github.com/rapideditor/agent-practices/blob/main/playbooks/package-checks.md) playbooks were considered in November 2026 and skipped. The package ships only SVGs and `data/icons.json`: there's no JavaScript entry point, CommonJS build or `.d.ts`, so arethetypeswrong has nothing to check, and publint already passes on the packed tarball.

Don't add an `exports` map either. It would block deep imports like `@rapideditor/temaki/icons/zoo.svg` and `dist/temaki-symbol.svg`, which is how consumers use the package. Revisit if the package ever gains a JavaScript entry point.
